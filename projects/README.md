# Real-World Projects

Hands-on projects designed to apply skills learned in each phase of the curriculum.

## Projects by Phase

### Phase 1: Python Foundations
- **[Sales Data Validator](phase_1/project_1_sales_validator/)** - Build a data entry validation system for sales records

### Phase 2: Data Workflows & Analytics
- **[Customer Segmentation Dashboard](phase_2/project_1_customer_segmentation/)** - Analyze customer data and create segments

### Phase 3: ML Fundamentals
- **[Sales Forecasting Model](phase_3/project_1_sales_forecasting/)** - Predict future sales using regression

### Phase 4: Advanced ML & MLOps
- **[Product Recommendation Engine](phase_4/project_1_recommendation_system/)** - Build a recommendation system

### Phase 5: Business Intelligence
- **[Executive KPI Dashboard](phase_5/project_1_kpi_dashboard/)** - Create a comprehensive BI dashboard

### Phase 6: Advanced BI & Cloud
- **[Cloud Data Pipeline](phase_6/project_1_data_pipeline/)** - Build an end-to-end data pipeline

### Phase 7: SQL & Database Mastery
- **[Database Performance Optimization](phase_7/project_1_db_optimization/)** - Optimize slow queries and design efficient schemas

## Project Structure

Each project includes:
- `README.md` - Business case, objectives, and evaluation rubric
- `data/` - Sample datasets (CSV, JSON, SQL dumps)
- `notebooks/` - Starter Jupyter notebooks with guided exercises
- `solution/` - Reference implementation

## Difficulty Levels

- 🟢 **Beginner**: Guided exercises with clear steps
- 🟡 **Intermediate**: Some guidance, more problem-solving required
- 🔴 **Advanced**: Minimal guidance, open-ended challenges

## Using Projects

1. Choose a project aligned with your current phase
2. Read the README for context and objectives
3. Load the dataset and explore it
4. Work through the starter notebook
5. Check your solution against the reference implementation
6. Share your results in [GitHub Discussions](../../discussions)
