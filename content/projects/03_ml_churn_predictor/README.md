> **Estimated time**: 6–10 hours

## 🎯 Project Overview

Build an **end-to-end machine learning pipeline** that predicts whether a telecom
customer will churn in the next 30 days. The project covers the full ML lifecycle:
EDA → feature engineering → model selection → evaluation → a deployable prediction
function.

This project proves you can:

- Frame a business problem as a supervised classification task (Phase 4)
- Build and compare multiple ML models with scikit-learn (Phase 4–5)
- Handle class imbalance, tune hyperparameters, and interpret results with SHAP (Phase 5)
- Package a model for production use (Phase 5)

---

## 📋 Business Scenario

**TelecomX** has 500,000 subscribers and loses ~5% per month to churn, costing
$2.4 M/month in lost revenue. The CRM team can run a targeted retention campaign
for $15/customer but needs to know *who* to target with 2 weeks' lead time.

Your goal: train a churn classifier with **AUC-ROC ≥ 0.80** so the CRM team can
prioritise the top-decile customers most likely to churn.

## ✅ Milestones

### Milestone 1 — EDA & Feature Engineering (Phase 4)

- [ ] Load the synthetic dataset generated by `_generate_dataset()`
- [ ] Print class distribution (`churn` column)
- [ ] Create features:
  - `avg_monthly_spend` = `total_spend / tenure_months`
  - `support_rate` = `support_tickets / tenure_months`
  - `plan_encoded` = ordinal encoding of `plan` (Basic=0, Standard=1, Premium=2)
- [ ] Identify and handle missing values

### Milestone 2 — Baseline Model (Phase 4)

- [ ] Split into train / test (80/20, stratified by `churn`)
- [ ] Build a Logistic Regression baseline in a sklearn Pipeline
- [ ] Report: Accuracy, Precision, Recall, F1, AUC-ROC
- [ ] Plot the ROC curve

### Milestone 3 — Improved Model (Phase 5)

- [ ] Address class imbalance with `class_weight="balanced"` or `SMOTE`
- [ ] Train a `GradientBoostingClassifier` or `XGBClassifier`
- [ ] Use `GridSearchCV` or `RandomizedSearchCV` for hyperparameter tuning
- [ ] Compare AUC-ROC vs baseline — target ≥ 0.80

### Milestone 4 — Explainability (Phase 5)

- [ ] Compute SHAP values for the best model
- [ ] Plot feature importance (SHAP bar plot)
- [ ] Write a 2-sentence business explanation of the top 3 drivers

### Milestone 5 — Serialise & Predict (Phase 5)

- [ ] Save the best pipeline with `joblib.dump()`
- [ ] Write a `predict_churn(customer_dict)` function that loads the model
  and returns `{"churn_probability": 0.72, "churn_flag": True}`
- [ ] Verify the function works end-to-end
