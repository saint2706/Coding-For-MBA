## Scripts Created

All scripts in `/scripts/` directory:

1. **gen_nav.py** - Navigation generator
   - Scans Day_XX_* folders
   - Groups by phase (1-7)
   - Generates mkdocs.yml nav structure
   - Creates backup (mkdocs.yml.bak)

2. **gen_phase_overviews.py** - Phase overview generator
   - Extracts lesson metadata from READMEs
   - Generates 7 phase overview pages
   - Includes lesson tables with descriptions

3. **add_tags.py** - Tag metadata generator
   - Adds YAML front-matter to lesson READMEs
   - Rule-based tag detection
   - Skips files with existing tags
   - Creates .bak backups

4. **gen_lessons_index.py** - Lessons index generator
   - Creates interactive index page
   - Generates site_metadata.json
   - Embedded search and filter JavaScript
   - Responsive CSS

5. **revert_nav_changes.py** - Rollback utility
   - Finds all .bak files
   - Restores to original names
   - Safety net for mistakes

6. **README.md** - Comprehensive documentation
   - Usage instructions for all scripts
   - Workflow and dependencies
   - Configuration and troubleshooting

## How Scripts Work

### Execution Order
```bash
# 1. Add tags to lessons
python scripts/add_tags.py --apply

# 2. Generate phase overviews
python scripts/gen_phase_overviews.py --apply

# 3. Create lessons index
python scripts/gen_lessons_index.py --apply

# 4. Update navigation
python scripts/gen_nav.py --apply
```

### Safety Features
- All scripts default to dry-run mode
- `--apply` flag required for changes
- Automatic .bak backup creation
- Idempotent (safe to run multiple times)
- Rollback available via revert_nav_changes.py
