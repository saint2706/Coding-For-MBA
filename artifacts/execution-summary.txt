## How to Run Scripts Locally

### Prerequisites
```bash
pip install -r requirements-dev.txt
```

### Script Execution Order
```bash
# 1. Add tags to lessons (creates YAML front-matter)
python scripts/add_tags.py --apply

# 2. Generate phase overview pages
python scripts/gen_phase_overviews.py --apply

# 3. Create interactive lessons index
python scripts/gen_lessons_index.py --apply

# 4. Update navigation structure
python scripts/gen_nav.py --apply

# 5. Build and serve
mkdocs build --strict
mkdocs serve
```
