# Day 85 – Advanced SQL and Performance Tuning

## Introduction

This lesson delves into advanced SQL techniques and performance tuning, essential skills for any business intelligence professional. We will explore complex queries, window functions, and indexing strategies to optimize database performance.

## Topics Covered

*   **Common Table Expressions (CTEs):** Learn how to simplify complex queries and improve readability.
*   **Window Functions:** Understand how to perform calculations across a set of table rows.
*   **Indexing Strategies:** Discover how to use indexes to speed up query performance.
*   **Query Optimization:** Learn how to analyze and optimize slow-running queries.

## Exercises

1.  Write a query using a CTE to find the top 10 customers by sales.
2.  Use a window function to calculate a 7-day moving average of sales.
3.  Analyze a query plan and suggest an appropriate index to improve performance.
