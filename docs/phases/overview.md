# Phase Overview

The curriculum is structured around seven progressive phases that take learners from Python
fundamentals through machine learning to business intelligence and database mastery.

| Phase | Days | Outcomes | | --- | --- | --- | | **[Phase 1 – Python Foundations](phase1.md)** |
01-20 | Core Python syntax, data structures, and file handling to automate repeatable business
workflows. | | **[Phase 2 – Data Analytics & Workflows](phase2.md)** | 21-39 | NumPy, Pandas,
databases, APIs, statistics, and visualization fundamentals for building analysis-ready datasets. |
| **[Phase 3 – Machine Learning Foundations](phase3.md)** | 40-54 | Regression, classification,
unsupervised learning, and neural networks with an applied business focus. | |
**[Phase 4 – Advanced ML & MLOps](phase4.md)** | 55-67 | Transformers, generative models,
deployment, monitoring, and production ML pipelines for operational excellence. | |
**[Phase 5 – Business Intelligence](phase5.md)** | 68-84 | BI strategy, analytics enablement, and
career planning to activate organization-wide insights. | |
**[Phase 6 – BI Advanced & Capstone](phase6.md)** | 85-90 | Advanced SQL, cloud BI platforms, data
governance, and comprehensive capstone project. | |
**[Phase 7 – SQL & Database Mastery](phase7.md)** | 91-108 | Comprehensive SQL training, database
design, optimization, and enterprise database features. |

## How to use this structure

Each phase builds on previous knowledge while remaining modular enough to revisit independently:

- **Linear path:** Progress through phases 1-7 sequentially for comprehensive mastery.
- **Targeted learning:** Jump to specific phases based on your current needs and background.
- **Skill refreshers:** Return to earlier phases to reinforce fundamentals or fill knowledge gaps.
