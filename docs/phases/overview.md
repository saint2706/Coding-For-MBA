# Phase overview

The curriculum is structured around five progressive phases that take learners from Python fundamentals to business intelligence leadership.

| Phase | Days | Outcomes |
| --- | --- | --- |
| **Phase 1 – Python Foundations** | 01-20 | Core Python syntax, data structures, and file handling so you can automate repeatable business workflows. |
| **Phase 2 – Data Workflows & Analytics Stack** | 21-39 | Databases, APIs, statistics, and visualization fundamentals for building analysis-ready datasets. |
| **Phase 3 – Machine Learning Foundations** | 40-54 | Regression, classification, unsupervised learning, and neural networks with an applied business focus. |
| **Phase 4 – Advanced ML & MLOps** | 55-67 | Deployment, monitoring, transformers, and production ML pipelines for operational excellence. |
| **Phase 5 – Business Intelligence Specialization** | 68-84 | BI strategy, analytics enablement, and career planning to activate organization-wide insights. |

Use the navigation tabs to jump into each phase, or browse the [complete lesson library](../lessons/_index.md).
