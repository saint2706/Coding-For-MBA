# Coding for MBA

> A 108-day applied Python, analytics, and business intelligence curriculum for decision-makers who
> want to ship production-ready insights.

## Quick start

1. **Clone the repo**
   ```bash
   git clone https://github.com/saint2706/Coding-For-MBA.git
   cd Coding-For-MBA
   ```
1. **Create a virtual environment**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
   ```
1. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   pip install -r requirements-dev.txt
   ```

## What you get

- Structured journey across five phases that balance technical execution with business storytelling.
- Repeatable lesson pattern with Python scripts, notebooks, and solution walk-throughs.
- Tooling for local development, CI, and documentation so you can learn by doing.
