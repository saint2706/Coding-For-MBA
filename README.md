## Who This Is For

Most MBA programs teach you to *talk* about data. This curriculum teaches you to *build with it.*

**Coding for MBA** is a structured, 140-day self-paced program purpose-built for:

- **MBA graduates and students** who want a credible technical edge in data-heavy roles
- **Business analysts and finance professionals** transitioning into data science or AI
- **Strategy and operations leaders** who need to understand what their engineering teams actually do
- **Product managers and consultants** who want to go deeper than dashboards
- **Anyone with a business background** who refuses to be left behind in the AI economy

You don't need prior programming experience. By Day 140, you'll be building production AI systems.

## The Curriculum: 12 Phases, 140 Days

The program is organized into 12 sequential phases — each building directly on the last. Difficulty ramps deliberately: you earn every concept before the next one arrives.

### Phase 1 — Algorithmic Thinking & Python Foundations `Days 1–12` `Beginner`

Before writing code, you learn to *think* like a programmer. The three-question framework (input / output / steps) becomes your default problem-solving mode. You then work through Python's core toolkit: variables, data types, control flow, functions, error handling, and list comprehensions. By Day 12, you're writing clean, Pythonic code that handles real business inputs gracefully.

**Skills unlocked:** Algorithmic thinking · Data types · Control flow · Functions · Error handling · Generators · Debugging

---

### Phase 2 — Functions, Modularity & Data Wrangling `Days 13–24` `Intermediate`

You move from scripts to programs. Higher-order functions, decorators, OOP, and file handling turn single-use code into reusable systems. Then NumPy and pandas arrive — and data processing at scale becomes routine. You finish with an Exploratory Data Analysis mini-capstone that mirrors real analyst workflows.

**Skills unlocked:** Higher-order functions · OOP · Exception handling · NumPy · pandas · EDA · Data cleaning

---

### Phase 3 — Data Engineering & Web Development `Days 25–36` `Intermediate`

The gap between "data analysis" and "software engineering" closes here. You build ETL pipelines, create data visualizations with Matplotlib and Plotly, and ship your first web applications with Flask and FastAPI. You also learn web scraping, APIs, and how data moves across the internet.

**Skills unlocked:** ETL · REST APIs · Flask/FastAPI · Web scraping · Data visualization · SQL fundamentals

---

### Phase 4 — Mathematical Foundations & ML Fundamentals `Days 37–48` `Intermediate`

The math behind machine learning — demystified. Linear algebra, probability, and statistics are taught through the lens of *why they matter for ML*, not for their own sake. You then apply that intuition to train your first supervised learning models: linear regression, logistic regression, decision trees, and ensemble methods.

**Skills unlocked:** Linear algebra · Probability · Statistics · Regression · Classification · Model evaluation

---

### Phase 5 — Advanced ML & Deep Learning `Days 49–60` `Advanced`

You cross the threshold from ML practitioner to ML engineer. Neural networks, CNNs, RNNs, and Transformers. Training from scratch vs. fine-tuning. Hyperparameter optimization, regularization, and everything that separates a notebook experiment from a deployable model.

**Skills unlocked:** Neural networks · CNNs · RNNs · Transformers · Transfer learning · MLOps basics

---

### Phase 6 — Cutting-Edge ML `Days 61–72` `Advanced`

Phase 5 made you an ML engineer. Phase 6 makes you an ML *architect*. Reinforcement learning, causal inference, generative models (GANs, VAEs, diffusion), model safety, and the systems-level thinking required to deploy AI responsibly at scale.

**Skills unlocked:** RL · Causal inference · Generative models · AI safety · Model governance · Deployment architecture

---

### Phase 7 — BI Analytics, Governance & Modern Data Stack `Days 73–84` `Advanced`

The command center of the modern enterprise. You learn how business intelligence works end-to-end: from data warehousing and dimensional modeling to dashboards, data governance, and the modern data stack (dbt, Airflow, Snowflake, BigQuery, Looker). You move from data worker to data leader.

**Skills unlocked:** Data warehousing · Dimensional modeling · dbt · Airflow · Snowflake · BigQuery · Governance · Modern data stack

---

### Phase 8 — SQL Mastery & Database Architecture `Days 85–96` `Advanced`

You stop writing SQL queries and start designing SQL *engines*. Window functions, CTEs, query planning, index architecture, normalization, and performance profiling. The database schema that will outlive a decade of application rewrites — designed well from Day 1.

**Skills unlocked:** Advanced SQL · Window functions · Query optimization · Index design · Database architecture · Normalization

---

### Phase 9 — Enterprise SQL Performance Engineering `Days 97–108` `Expert`

The capstone of database engineering. Anyone can write a query that works. This phase teaches you to write one that works at 3 AM on Black Friday when the database is on fire. Partitioning, sharding, replication, distributed SQL, and the operational playbooks that keep production systems alive.

**Skills unlocked:** Partitioning · Sharding · Replication · Distributed SQL · Query tuning at scale · Operational runbooks

---

### Phase 10 — Generative AI & LLM Engineering `Days 109–120` `Advanced`

The phase that closes the gap between talking about AI and building with it. RAG systems, fine-tuning with LoRA/QLoRA, production agents, LLM evaluation at scale, token optimization, vision-language models, and responsible AI design. Every topic maps directly to a critical skill gap in the 2025–2026 job market.

**Skills unlocked:** RAG · Fine-tuning · LLM agents · Tool use · Prompt engineering · LLM evaluation · AI ethics · VLMs

---

### Phase 11 — Cloud Data Engineering `Days 121–132` `Advanced`

From on-premises thinking to cloud-native architecture. You design and operate production data platforms on AWS, GCP, and Azure — with a multi-cloud perspective so you can work anywhere. Cost optimization, security, observability, and the systems that handle real-world scale without waking anyone up at 3 AM.

**Skills unlocked:** AWS · GCP · Azure · Cloud data pipelines · Cost optimization · Data platform security · Observability

---

### Phase 12 — Analytics Engineering & Data Products `Days 133–140` `Advanced`

Phase 11 built the engine. Phase 12 teaches you to drive it. Analytics engineering, metrics layers, self-serve analytics, and how to turn a data warehouse into a revenue-generating data product. You finish knowing how to take "we have data" to "$1M ARR from a data product."

**Skills unlocked:** Analytics engineering · Metrics layers · Self-serve analytics · Data products · Product analytics · Monetization

## The Web App

The curriculum lives inside a purpose-built interactive learning platform — not a PDF, not a video series, not a shared Google Doc.

### Features Designed for Deep Learning

**In-Browser Python Runner**
Run Python code directly in the browser — no setup, no terminal, no excuses. Powered by Pyodide (Python compiled to WebAssembly), the playground lets you experiment with every concept the moment you learn it.

**Progress Tracking & Resume**
Your completion state is saved locally. Open the app on any day and pick up exactly where you left off. Per-phase completion percentages give you an honest view of where you stand.

**Gamification That Respects Your Time**
XP points, achievements, study streaks, and daily challenges — designed to maintain momentum without turning learning into a slot machine. Unlock real milestones (`first-lesson`, `streak-7`, `quiz-master`, `xp-300`) as you progress.

**Full-Text Search**
Press `/` from any page to open the search palette. The index covers lesson titles, concepts, tags, phases, and body text — with code blocks stripped so prose matches stay relevant. Search works offline once assets are cached.

**Table of Contents & Reading Time**
Every lesson displays estimated reading time and a navigable table of contents. You always know how long a session will take before you start.

**Mastery Checks & Exercises**
Inline exercises and mastery checks reinforce concepts at the moment of learning — not as a separate quiz you'll forget to take.

**Related Lessons & Prerequisites**
Context-aware links surface the lessons you need to revisit and the ones worth reading next. No dead ends.

**Keyboard-First Navigation**
`/` to search · `Esc` to clear · sidebar shortcuts for phase navigation. The app stays out of your way.

**Offline-Ready**
Assets are cached after first load. Your curriculum is available on a plane.

| Layer | Technology |
|-------|-----------|
| Framework | React 19 + TypeScript 5.x |

| Testing | Vitest (unit) + Playwright (E2E) |

## Getting Started Locally

> Requires Node.js 18 or higher.

```bash
# Clone the repository
git clone https://github.com/saint2706/Coding-For-MBA.git
cd Coding-For-MBA

# Install dependencies
npm install

# Start the development server
npm run dev
# → App available at http://localhost:5173
```

### Available Scripts

| Script | Description |
|--------|-------------|
| `npm run dev` | Start Vite development server |
| `npm run build` | Production build (includes sitemap, typecheck) |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | TypeScript compiler check |
| `npm run format` | Format code with Prettier |
| `npm run validate-content` | Verify markdown content integrity |
| `npm test` | Run unit tests (Vitest) |
| `npm run test:coverage` | Unit tests with coverage report |
| `npm run test:e2e` | Playwright end-to-end tests |
| `npm run analyze` | Build + generate `dist/stats.html` bundle report |
| `npm run deploy` | Deploy to GitHub Pages |

## Deployment & CI

The platform runs on GitHub Pages with a CI/CD pipeline designed for zero-surprise deploys:

1. **CI** (`ci.yml`) — runs on every PR and push to `main`: linting, type checking, content validation, unit tests, and E2E tests.
2. **Deploy** (`deploy.yml`) — triggers automatically only after CI passes on `main`. Performs only deployment-critical steps (install, build, upload, deploy to Pages).
3. **Dependency Review** (`dependency-review.yml`) — blocks PRs that introduce high/critical vulnerabilities or license violations.
4. **Nightly Smoke** — Playwright E2E suite runs nightly to catch regressions before users report them.
5. **Lighthouse CI** — performance, accessibility, and SEO audits on every build.

**Environments:**
- **Primary:** `saint2706.github.io/Coding-For-MBA` (GitHub Pages, auto-deployed from `main`)
- **Preview:** `coding-for-mba.surge.sh` (optional, triggered manually or on published releases)

## Visual Snapshot Testing

Visual smoke tests capture deterministic full-page screenshots for six key routes (home, curriculum, phase 1, lesson 1, progress, search) and compare them via committed SHA-256 text snapshots — no binary image baselines, no flaky diffs.

To update snapshots intentionally:

```bash
npm run test:e2e -- --project=chromium tests/e2e/visual-smoke.spec.ts --update-snapshots
```
