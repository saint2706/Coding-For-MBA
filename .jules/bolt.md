## 2024-07-17 - ScrollProgress useRef Cache\n**Learning:** React component repeatedly called `document.querySelector` inside an animation frame during scroll events, causing unnecessary main-thread overhead and GC churn. Using `useRef` to cache the element reference prevents this.\n**Action:** Use `useRef` accompanied by `element.isConnected` to cache targeted DOM queries inside hot code paths (e.g., scroll handlers) to prevent repetitive DOM traversal.
