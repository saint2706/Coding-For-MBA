## 2024-07-14 - React.memo Pitfall with Inline Functions
**Learning:** Even when using `React.memo` with a custom `propsAreEqual` function, inline functions passed as props (like `onClose={() => setSidebarOpen(false)}` or `const togglePhase = (phaseNum: number) => { ... }`) can still cause performance issues. In `SidebarPhaseGroup`, `React.memo` is used, but in `App.tsx` and `Sidebar.tsx`, the `onClose` and `togglePhase` functions were being redefined on every render, which could defeat the purpose of `React.memo` if they were included in the default shallow comparison or if the custom `propsAreEqual` was ever refactored to rely on standard shallow checks.
**Action:** Always wrap event handler functions passed to memoized child components in `useCallback` to preserve reference equality across renders, ensuring `React.memo` functions optimally.
