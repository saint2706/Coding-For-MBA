## 2025-02-17 - Prevent reverse tabnabbing via DOMPurify localized hook
**Vulnerability:** DOMPurify integration when sanitizing SVG Mermaid diagrams explicitly allows `<foreignObject>` and `target` attributes but fails to ensure external links (`<a>` tags with `target="_blank"`) enforce `rel="noopener noreferrer"`. This could allow reversed tabnabbing (where the newly opened tab can manipulate the original tab's `window.opener`).
**Learning:** Using `DOMPurify.addHook` globally pollutes the DOMPurify configuration across the entire app. For localized usage without side effects, you must instantiate a local instance with `const localPurify = DOMPurify(window)` and attach the hook exclusively to that local instance.
**Prevention:** Whenever allowing the `target` attribute or rendering third party markdown/diagrams with potential external links, instantiate a local DOMPurify scope and explicitly attach a hook to enforce `rel="noopener noreferrer"` for any anchor tag containing a `target` attribute.
