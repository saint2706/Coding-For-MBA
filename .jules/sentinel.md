## 2025-05-24 - Fix DOMPurify XSS Bypass in MermaidDiagram
**Vulnerability:** DOMPurify was configured with `ADD_TAGS: ['foreignObject']` and `HTML_INTEGRATION_POINTS: { foreignobject: true }` but used an outdated version (`^3.4.11`) that was vulnerable to an XSS bypass via `CUSTOM_ELEMENT_HANDLING` (GHSA-c2j3-45gr-mqc4). The library was also missing the `RETURN_TRUSTED_TYPE: true` configuration, reducing defense-in-depth on supported browsers.
**Learning:** Even when applying strict configurations to sanitizers (like explicit tag whitelists), the underlying sanitization library must be kept up-to-date, especially when handling complex HTML integration points (like SVG `foreignObject`).
**Prevention:** Regularly run `npm audit` and ensure libraries parsing untrusted markup (like DOMPurify and markdown parsers) are pinned to patched versions. Always enable `RETURN_TRUSTED_TYPE: true` when injecting raw HTML strings to leverage browser-level Trusted Types protections.
