Day 1: Introduction to Python 🐍

Learn the foundational syntax of Python, why it's crucial for modern business analytics, and write your first script.

  • VS Code installed (covered in Day 0)

Why Python for Business?

Python has overtaken Excel as the tool of choice for heavy data lifting. While Excel struggles with datasets over 1 million rows, Python handles millions of records in seconds.

"The only way to learn a new programming language is by writing programs in it."
— Dennis Ritchie

Understanding Variables

Think of a variable as a labeled box where you store data. In Python, you don't need to declare the "type" of box—Python figures it out for you.

main.py 
revenue = 150000
cost = 85000

# Calculate Profit
profit = revenue - cost

print(f"Quarterly Profit: ${profit}")
info

MBA Note

Unlike Excel cell references (e.g., A1, B2), variables have semantic names. This makes your logic readable and auditable by your team.

Your First Script

Let's write a simple script to calculate the ROI of a marketing campaign. Open your IDE and type the following: 

ad_spend = 5000
conversions = 300
ltv = 120 # Lifetime Value

roi = ((conversions * ltv) - ad_spend) / ad_spend * 100

print(f"Campaign ROI: {roi}%")
